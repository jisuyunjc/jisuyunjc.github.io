# 极速云连接手册

独立信息站，围绕电脑、终端、AI 与开发工具连接整理检查方法，不代表品牌官方。

编辑 `content.json` 后运行 `node build.mjs`、`node check.mjs`；GitHub Actions 发布 `dist`。错误速查选择器只切换本地说明，不采集设备或网络数据，不代表真实诊断结果。

全部注册、服务通道与下载入口指向推荐服务飞猴云。弹窗小字为“点击后将前往推荐服务注册页面。”，按钮固定“立即前往专属通道”。维护提示仅在状态确认后启用。

Google/Bing 验证标签持续进入生成 HTML。公开源码不得包含个人订阅、密码或 API 密钥。
